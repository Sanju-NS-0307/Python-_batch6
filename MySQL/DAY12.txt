SET OPERATORS
=============
UNION 
-----
COMBINE RESULTS FROM THE TWO QUERIES AND REMOVE DUPLICATE ROWS.COLUMN MUST HAVE THE SAME NUMBER AND TYPE

UNION ALL
---------
COMBINES RESULTS FROM TWO QUERIES AND INCLUDE ALL ROWS,INCLUDING DUPLICATES.COLUMNS MUST HAVE THE SAME NUMBER
AND TYPE

INTERSECT
---------
RETURNS ROWS THAT ARE COMMON TO BOTH QUERIES.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE
NOTE:MYSQL DOESNT SUPPORT INTERSECT DIRECTLY

MINUS/EXCEPT
------------
RETURNS FROM THE FIRST QUERY THAT ARE NOT PRESENT IN THE SECOND QUERY.COLUMNS MUST HAVETHE SAME NUMBER AND TYPE.

JOINS
=====
A JOIN IN MYSQL IS USED TO COMBINE ROWS FROM TWO OR MORE TABLES BASED ON RELATED COLUMNS

EXAMPLE:
EMPLOYEES TABLE-->EMPLOYEE DETAILS
DEPARTMENT TABLE-->DEPARTMENT DETAILS

ID YOU WANT TO SEE WHICH EMPLOYEE BELONGINGS TO WHICH DEPARTMENT.YOU NEED TO JOIN THESE TWO TABLES

WHY DO WE NEED JOINS
--------------------
1.TO FETCH DATA FROM MULTIPLE TABLES IN A SINGLE QUERY
2.TO REDUCE DATA DUPLICATION (INSTEAD OF KEEPING EVERYTHING IN ONE TABLE)
3.TO IMPLEMENT RELATIONSHIPS LIKE(ONE-TO ONE,ONE-TO-MANY,MANY-TO-ONE,MANY-TO-MANY)
4.TO GENERATE REPORTS AND ANALYTICS COMBING DIFFERENT DATABASES.


TYPES OF JOINS
==============
1.INNER JOIN
2.LEFT JOIN
3.RIGHT JOIN
4.FULL JOIN
5.CROSS JOIN
6.SELF JOIN

1)INNER JOIN
============
RETURN ONLY THE ROWS THAT HAVE MATCHING VALUES IN BOTH TABLES
SYNATAX
-------
SELECT COLUMNS
FROM TABLE1
INNER JOIN TABLE2
ON TABLE.COMMON_COLUMN=TABLE2.COMMON_COLUMN;

2.LEFT JOIN
===========
RETURNS ALL ROWS FROM THE LEFT TABLE AND THE MATCHED ROWS FROM THE RIGHT TABLE IF NO MATCH VALUES APPEAR FOR THE RIGHT TABLE COLUMNS
SYNTAX
-------
SELECT COLUMNS
FROM TABLE1
LEFT JOIN TABLE2
ON TABLE.COMMON_COLUMN=TABLE2.COMMON_COLUMN;


3.RIGHT JOIN
============
RETURNS ALL ROWS FROM THE RIGHT TABLE AND THE MATCHED ROWS FROM THE LEFT TABLE.IF NO MATCH NULL VALUES APPEAR FOR THE LEFT TABLE COLUMNS
SYNTAX
-------
SELECT COLUMNS
FROM TABLE1
RIGHT JOIN TABLE2
ON TABLE.COMMON_COLUMN=TABLE2.COMMON_COLUMN;



4.FULL JOIN
===========
TO STIMULATE THE USE THE UNION OF LEFT JOIN AND RIGHT JOIN
SYNTAX
-------
SELECT COLUMNS
FROM TABLE1
LEFT JOIN TABLE2
ON TABLE.COMMON_COLUMN=TABLE2.COMMON_COLUMN
UNION
SELECT COLUMNS
FROM TABLE1
RIGHT JOIN TABLE2
ON TABLE.COMMON_COLUMN=TABLE2.COMMON_COLUMN;


5.CROSS JOIN
===========
RETURNS CARTESIAN PRODUCT-->EVERY ROW FROM THE FIRST TABLE WITH EVERY ROW FROM THE SECOND TABLE
SYNTAX
------
SELECT COLUMNS
FROM TABLE1
CROSS JOIN TABLE2;

6.SELF JOIN
===========
A TABLE JOINED WITH ITSELF.
SYNTAX
------
SELECT A.COLUMNS,B.COLUMNS
FROM TABLE1 A
INNER JOIN TABLE1 B
ON A.COMMON_COLUMN=B.COMMON_COLUMN;
