what is data?
-------------
raw facts or figures without context
ex:101,malli,hyd,50000

what is field?
--------------
smallest unit of data in database(column/attribute)
ex:ename,esalary,eid

what is record?
---------------
collection of related fields(row/tuple)
ex:101,'sunny',50000

what is database?
-----------------
organized collection of related records stored together
ex:an employee database containing all employee records.

client-server-arch
------------------
client: the role of the client-server arch is to request to the server and to get response from the server.

server:server is a software .the role of the server in client -server arch is to take request from the clients
if the request is valid request it will generate some response and we can handover that response to client.
if the client request is not valid request it will raise some error status codes.

protocol:it has a set of rules and regulations.the role of the protocol in the client-server arch is to send request from client to server.


Identifiers
============
a-z,A-Z,0-9,_,# only should be used and allowed
identifier should not start with digit
spaces are not considered to declare identifiers
reserved words not considered to declare identifiers
max length to declare identifiers is 15(for better approach)and can take even more.


SQL(structured query language)
==============================
Structured query language(sql) is a standardized programming language specially designed for managing and manipulating relational databases.it provides a declarivte syntax that allows users to define what data they want retrieve,insert,update or delete without specifying exactly how database should execute these operations.

DML:(Data Manipulation language)
-------------------------------
manages data stored within database objects(insert,update,delete)

DCL(Data Control Language)
--------------------------
manages permissions and access control on database objects.

TCL(Transaction control language)
---------------------------------
manages transaction to maintain data integrity.

DQl(Data Query Language)
------------------------
used to fetch/retrieve data from the database.
